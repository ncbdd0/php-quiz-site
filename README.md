# PHP 程序设计 · 学生自主答题（纯静态网页）

一个无需服务器、无需数据库、离线可用的学生自主答题网站。**个人使用**。

题库来自：
- 《PHP作业题库.docx》
- 《PHP作业题库答案与解析.docx》
- 《PHP同源练习题_3套150题(1).docx》

知识库来自：《PHP期末精简学习笔记_按题库重排.docx》（14 章主线 + 3 附录，按章节分类导入，见下文"知识库"）。

- 《PHP作业题库.docx》—— 322 题（第一部分 no4.homework 82 题：单选 50 + 多选 32；第二部分 no6 homework 240 题：单选 120 + 填空 120）
- 《PHP作业题库答案与解析.docx》—— 每题的【答案】与【解析】
- 《PHP同源练习题_3套150题(1).docx》—— **扩展题库** 150 题（3 套 × 50 题：单选 20 + 多选 5 + 填空 15 + 编程 10），答案附于该文档文末

共 **472 题**，四个题型：单选 230 / 多选 47 / 填空 165 / 编程 30。

> **判分原则**：主题库一律以答案文档中的【答案】为准，扩展题库一律以原文档文末参考答案为准，答案数据未做任何人工改动；解析仅供参考展示。

## 快速开始

**方式一（最简单）**：直接双击 `index.html`，用浏览器打开即可使用（Chrome / Edge / Safari 均可，无需联网；手机浏览器同样可用）。

**方式二（本地服务器，可选）**：

```bash
cd php-quiz-site
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 进站密码（= 数据密钥）

- 打开页面需先输入**进站密码**。密码不只是界面门禁，而是**真正的数据密钥**：
  题库与知识库以 **AES-256-CTR 密文**（`js/secure.js`）随仓库分发，密码经
  PBKDF2-HMAC-SHA256（20000 轮加盐）派生出 AES 密钥，在浏览器里解密后才能使用。
- **仓库里没有任何明文题目**——下载整个仓库、翻源码、看网络请求，拿到的都只是密文；
  密码错误则解密失败，无法进入，也无法还原题库。
- **防暴力破解**：连续输错 5 次将临时锁定 60 秒，之后每再错 5 次锁定时间翻倍（上限 15 分钟）。
- 解锁后 **7 天内免输入**（本机缓存派生密钥，仅存于本设备 localStorage）；想立即重新锁定可清除浏览器站点数据。
- 密码保护强度取决于密码本身，请勿使用弱密码。分享方式：把**网址 + 密码**发给指定的人即可。
- 如需修改密码：重新运行 `python3 tools/encrypt_data.py --password '新密码'` 生成新 `js/secure.js` 并提交（见下文"重新生成题库数据"）。

## 两种模式

| | 背题模式 | 答题模式 |
|---|---|---|
| 呈现方式 | **题目与答案直接呈现**：正确选项高亮打勾、填空直接填入参考答案、编程题展示参考代码，附解析与知识点入口 | 先自行作答，点击「下一题」后**立即判分**，显示正确答案与解析 |
| 作答与交卷 | 无需作答、无交卷；答题卡记录已浏览进度，最后一题点「完成背诵」即结束 | 已判分题目锁定，可回看但不可改；交卷后另有总成绩与复盘 |
| 适用场景 | 纯记忆背诵、快速过题 | 模拟考试、逐题搞懂 |

### 通用功能

- **进站密码**：打开即锁定，防暴力破解临时锁定，7 天免输
- **练习范围（可多选）**：全部题库 / 第一部分 / 第二部分 / 扩展题库·同源练习题——可同时勾选多个题库混合出题
- **题型筛选**：单选 / 多选 / 填空 / 编程（显示各题型题数）
- **题量**：全部 / 20 / 30 / 50 / 100 题
- **随机打乱题目顺序**：每次练习的题目排列随机
- **打乱选择题选项顺序**：每次练习的选择题选项随机重排，并按新位置重新编号 A/B/C/D，正确答案同步对应新编号；同一练习内回看顺序保持不变，关闭开关即恢复原文顺序
- **错题本**：答错的题自动入本并累计答错次数；题目页「＋ 错题本」与复盘页每题按钮可手动添加/移除；错题本内可勾选题目单独练习（支持打乱顺序），也可删除所选或清空
- **自选题练习**：浏览全部 472 题，按题库/题型/题干关键词筛选，逐题勾选组成自己的题单（localStorage 持久化，下次打开还在）；支持全选/取消当前筛选、加载更多分页，想练哪题勾哪题
- **知识库**：《PHP期末精简学习笔记》按章节导入（13 章主线 + 3 附录），含正文、代码示例、表格、"题库落点"与"易错点"高亮卡；支持关键词搜索章节与正文，上一章/下一章连贯阅读
- **答错联动知识点**：答题模式答错时，判定区直接给出"📖 知识点：第 X 章 …"按钮，一键跳转对应章节；复盘页答错/未答的题目卡与错题本卡片同样带知识点入口；从答题页/成绩页跳转后可原路返回，会话不中断
- **答题卡**：点击题号任意跳转，已答/未答一目了然
- **计时**：自动记录用时
- **成绩页**：正确率、答对/答错/未答统计、逐题复盘（可按"全部/答错/未答"筛选）
- **只练错题**：一键重练本次答错与未答的题目
- **快捷键**：`A`–`H` 选中选项（多选可连按切换），`Enter` / `→` 下一题，`←` 上一题
- **移动端适配**：安卓 / iOS 手机浏览器可用，触控目标 ≥44px、无横向滚动、吸底操作栏，iPhone 输入不触发页面缩放
- 上次的选择（模式/范围/题型/打乱开关等）会自动记忆（localStorage）；错题本数据也保存在本机浏览器中

### 判分规则

- **单选题**：所选字母与答案一致即正确。
- **多选题**：所选字母集合与答案完全一致才正确（少选、多选均算错）。
- **选项打乱**：开启后选项按新顺序重新编号，判分与回显均以打乱后的编号为准（原始题库数据始终不变，每次练习重新随机）。
- **填空题**：逐空自动比对，忽略大小写、空格、全角/半角与尾部标点；参考答案带尾部括注时（如"简短风格（<? ?>）"），回答括注前的主要部分也算对；参考答案含"或"时（如扩展题库第1套第35题"// 或 #"），任一写法均判对。个别题存在多种正确写法，自动判分仅供参考，请以回显的参考答案自行核对。
- **编程题（自评不计分）**：仅存在于扩展题库，无法自动判分——答题模式点「下一题（查看答案）」对照参考答案自评；背题模式直接显示参考代码。编程题不计入正确率与对错统计，交卷确认也不会提示未作答。
- 少量题目（原卷 180 / 220 / 227 / 240 等）题干下划线数量与答案空数不一致，作答界面会自动改用"第1空/第2空…"编号输入框，与答案文档的空位编号一一对应；扩展题库填空的空数按题干下划线确定（如双空题）。

## 目录结构

```
php-quiz-site/
├── index.html              # 页面（首页 / 答题页 / 成绩页，单页应用）
├── css/style.css           # 「试卷批改」主题样式（纯本地，无外部依赖）
├── js/
│   ├── secure.js           # 加密题库 + 知识库（密文，由 encrypt_data.py 生成，勿手改）
│   ├── core.js             # 纯逻辑：判分、题干渲染、组卷、AES/PBKDF2 解密
│   └── app.js              # 页面交互（解锁后初始化）
├── tools/
│   ├── parse_questions.py  # docx → data.js 解析脚本（本地明文，不入库）
│   ├── parse_notes.py      # 学习笔记 docx → notes.js（本地明文，不入库）
│   ├── encrypt_data.py     # 明文 → secure.js 加密脚本
│   ├── smoke_test.js       # 冒烟测试（node tools/smoke_test.js）
│   └── parsed_debug.json   # 解析中间产物（调试用，不入库）
└── README.md
```

> 明文 `js/data.js` / `js/notes.js` 只存在于本地工作区（已列入 `.gitignore`），
> 仓库与线上只保留 `secure.js` 密文。

## 重新生成题库数据

当 Word 文档有更新时，重新生成并加密：

```bash
# 在 php-quiz-site 的上一级目录（即各 docx 所在目录）执行
python3 php-quiz-site/tools/parse_questions.py   # 题库 → js/data.js（明文，本地）
python3 php-quiz-site/tools/parse_notes.py       # 笔记 → js/notes.js（明文，本地）
python3 php-quiz-site/tools/encrypt_data.py --password '你的密码'   # → js/secure.js（密文，入库）
QUIZ_PW='你的密码' node php-quiz-site/tools/smoke_test.js           # 完整回归（含解密回环）
```

解析脚本会自动完成：主题库题干/选项解析、答案匹配、题干一致性抽查（防编号错位）、填空空数校验；扩展题库按"第N套 + 小节题型"解析题目、按文末"第N套答案 + 题型行"匹配答案（以"套+题号"关联，每套内编号 1–50）。解析脚本不做任何答案修改。

> 换密码 = 重新跑一遍 `encrypt_data.py --password '新密码'` 再提交即可，
> 所有用户端用新密码重新解锁。

## 后续部署到 GitHub Pages

本站为纯静态页面，可直接托管：

1. 在 GitHub 新建仓库（如 `php-quiz-site`），把本文件夹内容推送上去：
   ```bash
   cd php-quiz-site
   git init
   git add .
   git commit -m "init: PHP 题库答题网站"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/php-quiz-site.git
   git push -u origin main
   ```
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支 `/ (root)`，保存。
3. 稍等一两分钟，访问 `https://<你的用户名>.github.io/php-quiz-site/` 即可。

> 也可以保持 `index.html` 在仓库根目录，Pages 地址就是 `https://<用户名>.github.io/<仓库名>/`。
